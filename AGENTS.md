# AI Collaboration Conventions

## Core Rules & Context


## Preferred Conventions
- Use Markdown tables or bullet points for structured data and financial breakdowns.
- Format all numbers clearly (e.g., standard currency formatting, exact percentages, clear timeframes).
- Keep executive summaries concise (under 4 sentences) before presenting detailed analysis.
- Provide clear context when using accounting terminology (e.g., distinguishing GAAP vs. Tax standards, or managerial vs. financial accounting).

## Accounting & Financial Guardrails
- **Verification First**: Always verify mathematical calculations step-by-step before presenting final totals or outputs.
- **Audit-Ready Documentation**: Structure deliverables so supporting logic, assumptions, and data sources are clearly traceable.
- **Regulatory Compliance**: Align tax and reporting references with relevant federal and state standards (e.g., IRS tax forms, state excise tax, grant reporting guidelines)[cite: 1].

## Execution Rules
- Break down complex financial or strategic business cases into clear, actionable steps.
- Organize outputs using clean headers, bullet points, and high-visibility tables for readability.
